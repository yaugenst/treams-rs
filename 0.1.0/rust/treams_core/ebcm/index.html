Module ebcm 

Source
Expand description

Q-matrices of the extended boundary condition method (EBCM) for particles that are symmetric about the z axis, with analytic gradients for the surface and the media.

Upstream: treams.ebcm. qmat computes treams.ebcm.qmat with two differences:

  • radial_area_factor = true includes the factor r of the surface element (r rhat - r' theta-hat) r sin(theta) dtheta dphi, which treams omits; false reproduces treams. See https://yaugenst.github.io/treams-rs/latest/coming-from-treams/differences/.
  • It sums over the fixed polar nodes and weights of a Surface; the Python ebcm.qmat passes Gauss-Legendre nodes. treams integrates each matrix entry with the adaptive scipy.integrate.quad.
