Module legendre 

Source
Expand description

Associated Legendre functions of integer degree and the vector-wave angular functions pi and tau, with analytic argument derivatives. Real-degree Legendre values come from the Ferrers functions in ferrers.

Upstream: treams.special.lpmv, pi_fun and tau_fun (_waves.pyx).
