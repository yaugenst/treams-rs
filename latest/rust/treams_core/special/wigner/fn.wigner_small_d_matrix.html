pub(crate) fn wigner_small_d_matrix(l: i32, theta: f64) -> Result<DMatrix<f64>>
Expand description

Complete real Wigner small-d matrix d^l(theta) of one degree, rows and columns ordered -l..=l, for multipole rotations. A symmetric angular-momentum eigensystem avoids factorial-sum cancellation.
