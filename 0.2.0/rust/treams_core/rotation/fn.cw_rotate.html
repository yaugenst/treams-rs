Expand description

Rotation coefficient of one cylindrical mode pair about the z axis.

For the angle phi, the coefficient from (qz, m, q) to (kz, mu, p) is exp(-i m phi) for equal modes and zero otherwise. The polarizations p and q must be 0 or 1, the axial wavenumbers and phi finite, and the orders satisfy |mu|, |m| <= 128 (MAX_DEGREE). The labels are i64 so that every integer label gets these checks before its conversion.

Upstream: treams.cw.rotate. Differences: treams accepts orders above 128 and non-finite arguments, where this function gives an error.
