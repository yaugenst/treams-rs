Expand description

Reverse the shared matrix assembly in fixed column, side and multipole order. Each column writes its own transverse gradient; only the shared gradients enter the ordered reduction. Construct channels before skipping zero-weight entries, preserving validation and avoiding evaluation of unused, possibly overflowing jets.
