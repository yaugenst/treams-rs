Module interaction 

Source
Expand description

Dense solves of (I - T C) X = T B through one LU factorization of I - T C.

interaction returns the full interacting T-matrix X = (I - T C)⁻¹ T. InteractionFactor keeps the factorization and solves only requested incident fields B, any number of times.

Upstream: treams.TMatrix.interaction.solve() for interaction. InteractionFactor is a treams-rs extension.
