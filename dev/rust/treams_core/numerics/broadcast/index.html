Elementwise evaluation over broadcast inputs, and its pullback. treams-rs extension.

Each input is a scalar (length one) or has the common output length, as in NumPy broadcasting of one-dimensional arrays. The pullback turns the cotangent of each output, the gradient of a real loss with respect to that output, into the cotangents of the inputs. A scalar input’s cotangent is the sum of its per-output cotangents, added in output order on every schedule, so the thread count never changes it.
