Expand description

Interface from wavenumbers and impedances, indexed by medium (negative side, then positive side), and the real transverse wavevector q.

axis is the Cartesian normal, and q holds the two components after it in cyclic order. Returns four helicity scattering blocks with polarization order (0, 1). With fixed_q, the pullback holds q fixed and returns a zero q gradient.
