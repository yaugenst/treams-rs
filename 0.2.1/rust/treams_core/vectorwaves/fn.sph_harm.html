pub fn sph_harm(l: i32, m: i32, theta: Complex, phi: Complex) -> Result<Complex>
Expand description

Scalar spherical harmonic Y_l^m(theta, phi) at the polar angle theta and the azimuth phi.

Y is -i times the radial component of the Family::HarmonicZ wave (sph_harm_from_vsh_z).

Upstream: treams.special.sph_harm, which takes (m, l, phi, theta). Differences: degrees outside [0, 128], orders with |m| > 128 and non-finite angles give an error, where treams returns a value or NaN; other orders with |m| > l give zero, where treams returns NaN.
