Module plan

Expand description

Couplings of complete mode blocks, computed once and shared by every pair of positions, with the radial functions and harmonics evaluated once per displacement.

Upstream: treams.sw.translate, which evaluates one entry at a time; a plan gives the same coefficients for a whole block.
