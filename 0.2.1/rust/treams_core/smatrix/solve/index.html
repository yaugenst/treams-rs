Module solve 

Source
Expand description

The internal fields between two adjacent stacks: a certified Krylov or pivoted LU solve of (I - L1 U2) up = rhs, kept for the pullback.

Upstream: the numpy.linalg.solve inside treams.SMatrices.illuminate with a second S-matrix. The Krylov branch and its contraction test are treams-rs extensions.

L1 is the reflection of the lower stack for waves incident from the positive side (above) and U2 the reflection of the upper stack for waves incident from the negative side (below), so up holds the upgoing fields between the stacks.
